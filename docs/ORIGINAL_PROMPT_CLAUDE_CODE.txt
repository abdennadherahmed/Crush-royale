   ```
   finalScore = baseScore * cascadeMultiplier * comboMeterBonus
   ```

TASK 5: Trophy & Ranking System
------
Generate TrophySystem.cs that:

1. Trophy Calculation Engine:
   ```
   Victory:
   - If opponent_mmr > player_mmr: +40 + (difference * 0.5)
   - If opponent_mmr ≈ player_mmr: +25
   - Else: +10
   - Win streak bonus: +5 per win in current streak (max +20)
   
   Defeat:
   - If opponent_mmr > player_mmr: -5
   - If opponent_mmr ≈ player_mmr: -15
   - Else: -35 (anti-boosting harsh penalty)
   ```

2. League Calculation:
   ```
   Bronze:     0-299
   Silver:     300-699
   Gold:       700-1199
   Platinum:   1200-1799
   Diamond:    1800-2499
   Master:     2500+
   ```

3. Matchmaking Algorithm:
   ```
   targetTrophies = playerTrophies ± (random * 10% ± winStreakBonus)
   Ensure: trophy difference < 300 (max deviation)
   If difference > 200: Extra points multiplier
   If difference < 50: Reduced points
   ```

4. Weekly Reset:
   - Every Sunday midnight UTC
   - Store top 100 per league
   - Calculate rewards based on final league
   - Reset all player trophies (except history)
   - Archive leaderboards for records

5. Anti-Boosting Detection:
   - Flag: Win rate > 95%
   - Flag: Trophy gains > 200 per day consistently
   - Flag: Win streak > 50 against same opponent
   - Soft action: Require pause before next match

Code Requirements:
- Method: CalculateTrophyGain(int playerTrophies, int opponentTrophies, bool won) → int
- Method: GetLeagueName(int trophies) → string
- Method: GetCurrentWinStreak() → int
- Method: ResetSeasonalData() → bool
- Persist: PlayerTrophyHistory (for replays, stats)
- Database schema for leaderboards
